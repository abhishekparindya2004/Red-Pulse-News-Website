Help / How this Admin Works

This is a demo CMS (browser LocalStorage). Use it for assignments.

✅ Admin saves content in LocalStorage:
• rp_content (stories)
• rp_ticker (ticker labels/text)
• rp_notifications (notifications)
• rp_settings (brand settings)

🔥 To make your pages automatically read ticker/settings/notifications, you can add a tiny loader in your app.js (safe, front-end only).

For story lists, easiest is: use the HTML Generator tab and paste the generated cards into each page. (Because your pages are static HTML.)
